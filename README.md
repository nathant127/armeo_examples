# armeo_examples

This repository is a set of examples to showcase how to control the Armeo Power Robotic Exoskeleton, see [armeo_docs](https://github.com/nathant127/armeo_docs) for more documentation on the Armeo Power.

## Dependencies

- cmake
- c++
- xpctarget_api_cpp (included as submodule)
- linux (relies on unix sys/socket.h)

## Build

```bash
git clone https://github.com/nathant127/armeo_examples
cd armeo_examples
git submodule update --init

mkdir build
cd build
cmake ..
make
```

## Usage

Simply run any of the executables in the build directory.


## Examples

### print_state
This example simply prints the state of the Armeo without moving it including:

- Joint angles
- Joint velocities
- End effector position
- Jacobian

### teleop
This example provides a torque based teleoperation mode that shows how to use the Direct Torque operation mode.

### test_traj
This example uses mobilization mode to move a joint in a loop between two positions, you may modify the code to test other joints/positions if you would like.

### collect_data
This example simply collects the Armeo's state into a .csv file for later analysis

### test_dh
This example performs fkine using estimated dh parameters and compares the resulting estimated position to the position generated by the Armeo, it then writes the results to a .csv

### vel_control
This is a mode that allows you to use the keyboard to test the service mode, changing the option and the test joint on the fly.

### record_replay
This example should not be run as it does not work, but has been left in as there is potential for further investigations to uncover the purpose of replay mode.
